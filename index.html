Two modes · One config

One config. Two build modes.

Whether you're building a polished marketing page or a deep documentation hub, runvil.yaml is your single source of truth. The CLI detects your intent and delegates to the right engine.

  • SSG mode for structured pages with layouts & components
  • Book mode for Markdown-driven documentation
  • Unified theme system across both modes
runvil.yaml · SSG mode
          title: My Site
theme:
  default: auto

# SSG mode: layouts + components + pages
ssg:
  layouts:
    - name: main
      body: "<html></html>"
  components:
    - name: Hero
      body: "<h1>Hello, Runvil!</h1>"
      style: "h1 { color: var(--primary) }"
  pages:
    - path: /
      layout: main
      root: Hero

The Difference

Runvil vs. the alternatives

No node_modules, no build pipelines, no config sprawl — just Go doing what Go does best.

Runvil

  • One declarative runvil.yaml
  • Pure static HTML/CSS output
  • Zero runtime, zero dependencies
  • Single Go binary, ships fast

JS Frameworks

  • Node toolchain & config sprawl
  • Hydration & runtime JS by default
  • Lockfile churn & upgrades
  • Heavy build pipelines

Hand-rolled Scripts

  • You write the whole generator
  • No themes, no components, no routing
  • Fragile, hard to maintain
  • No documentation mode
