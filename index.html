A meta-framework, written in Go.

Runvil composes modules sourced across multiple ecosystems and repositories into one cohesive, high-performance foundation for building web services, CLI tools, background workers, and desktop applications.

Read the documentation Browse the code

Why Runvil

  • Meta-framework by design — integrates what other ecosystems do well instead of re-implementing it.
  • Stdlib-first — argument parsing, logging, and configuration come from the Go standard library.
  • Safe by design — Go's memory safety, no unsafe, no manual memory management.
  • Spec-driven — every component ships with a formal specification describing requirements and conventions.
  • Dogfooded — Runvil's own tooling and websites are built with Runvil.

Getting started

Scaffold a new Runvil project in seconds with the developer tool.

go install github.com/runvil/runvil/cmd/runvil@v0.1.0
runvil new hello --module example.com/hello
cd hello && runvil test
